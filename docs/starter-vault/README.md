# Welcome to Hatchdoor

Hatchdoor is a self-hosted web app for browsing, searching, editing, and sharing an Obsidian-style Markdown vault.

Your Markdown files are the source of truth. Hatchdoor builds a searchable SQLite view from those files, but the notes themselves remain plain files on disk. You can open them in Hatchdoor, edit them in Obsidian, keep them in git, or work with them using any tool that understands Markdown.

## A simple first workflow

1. Capture new ideas or notes quickly.
2. Link related notes with `[[wikilinks]]`.
3. Use search to find notes by meaning or exact wording.
4. Move stable notes into a folder structure that makes sense to you.
5. Archive old material instead of deleting it when you may need it later.

Hatchdoor does not require any specific folder layout. The example structure in this starter vault is only a suggested starting point.
