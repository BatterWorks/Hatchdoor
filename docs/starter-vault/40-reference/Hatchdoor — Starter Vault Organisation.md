# Hatchdoor — Starter Vault Organisation

Hatchdoor works with any folder layout. This note shows one optional structure that works well for a new vault.

Use it if you want a clear starting point. Ignore it if your existing vault already has a system that works.

## Suggested folders

- `00-inbox/` — quick capture for unsorted notes.
- `10-topics/` — evergreen topic pages and knowledge you expect to revisit.
- `20-projects/` — active efforts with an outcome or next action.
- `30-areas/` — ongoing responsibilities that do not have a finish line.
- `40-reference/` — stable information, guides, runbooks, and saved material.
- `90-archive/` — completed, inactive, or old notes.

The numbers keep folders in a predictable order in file browsers.

## How to choose a folder

Use `00-inbox/` when you are not sure yet.

Use `10-topics/` for ideas and subjects that can grow over time:

- `Coffee`
- `Home Networking`
- `Productivity`

Use `20-projects/` for active outcomes:

- `Launch personal website`
- `Plan kitchen renovation`
- `Prepare conference talk`

Use `30-areas/` for things you maintain:

- `Health`
- `Finances`
- `Home`

Use `40-reference/` for material you want to keep:

- setup notes
- checklists
- manuals
- technical references
- saved research

Use `90-archive/` when something is no longer active but may still be useful later.

## Index notes

Index notes are optional but helpful once a folder grows.

Common examples:

- [[Topics Index]]
- [[Projects Index]]
- [[Areas Index]]

An index note should stay short. Link to the important notes and leave the details inside those notes.

## Keep it flexible

A good vault structure should reduce friction. If deciding where something goes takes too long, put it in `00-inbox/` and move it later.

Hatchdoor search and wikilinks matter more than perfect folders.
